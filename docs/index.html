Minecraft VR for Intel Arc

DigammaXR is a Vivecraft fork for playing Minecraft Java in VR on Intel Arc graphics through Virtual Desktop. It includes tracked hands, motion controls, joystick movement, VR menus and familiar Vivecraft gameplay.
