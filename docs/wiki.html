DigammaXR is a virtual reality client modification for Minecraft Java Edition. It is a Vivecraft fork made for playing through Virtual Desktop's VDXR OpenXR runtime, with particular focus on Intel Arc graphics. It provides stereoscopic rendering, tracked controllers, VR hands, room-scale interaction, joystick movement, turning, menus and inventory controls.

DigammaXR is installed only on the client. Do not install DigammaXR and another Vivecraft build in the same instance.

Quick start

  1. Install Fabric Loader for Minecraft 1.20.4.
  2. Place the DigammaXR JAR in the instance's mods folder.
  3. Open Virtual Desktop Streamer and select VDXR as the OpenXR runtime.
  4. Connect the Quest headset to Virtual Desktop.
  5. Launch the Fabric 1.20.4 instance and enter a world.

If VR does not start, verify the runtime and connection before changing Minecraft graphics settings.

Installation

Prism Launcher

  1. Create or select a Minecraft 1.20.4 instance.
  2. Choose Edit → Version and install Fabric Loader.
  3. Open Mods, choose Add file and select the DigammaXR JAR.
  4. Confirm that no second Vivecraft or VR renderer JAR is enabled.
  5. Set the Java runtime to a 64-bit Java 17 installation.

Standard launcher

  1. Install Fabric Loader for 1.20.4.
  2. Open the Minecraft game directory.
  3. Create the mods folder if it does not exist.
  4. Copy the DigammaXR JAR into that folder and launch the Fabric profile.

Virtual Desktop and VDXR

  1. Start Virtual Desktop Streamer on the PC.
  2. Set the preferred OpenXR runtime to VDXR.
  3. Start Virtual Desktop in the headset and connect to the PC.
  4. Wait until both controllers are visible and tracked.
  5. Only then launch Minecraft.

SteamVR is not required for the supported path. If SteamVR opens automatically, close Minecraft, confirm VDXR is selected and reconnect Virtual Desktop before trying again.

Starting and leaving VR

Connect the headset before launching the game. DigammaXR initializes the VR session when the OpenXR runtime and headset are available. Enter a world after the VR view appears.

To return to flat play, close Minecraft normally and disconnect the headset. If a session becomes stuck, close Minecraft and Virtual Desktop completely before reconnecting.

Menus

Point at a menu with the controller. Use the right trigger to select. Controller behavior can change depending on the active VR menu and Minecraft key bindings.

Movement and play modes

The left stick acts like Minecraft's movement keys; physical room movement remains available for room-scale interaction. The right stick turns the player without requiring the user to rotate physically.

Standing

Uses headset height and controller positions for room-scale play. Keep a clear play space and recenter before beginning.

Seated

Recommended when playing from a chair. Use controller movement and turning rather than walking around the room.

Jumping and stepping

Auto-jump may assist with climbing blocks. The jump binding is the fallback when automatic movement cannot cross an obstacle.

VR settings

Use the in-game VR settings for:

  • Standing or seated play
  • Controller or headset-relative movement
  • Snap-turn angle and turning behavior
  • Teleporting and comfort options
  • HUD distance, scale and position
  • Menu, keyboard and radial-menu behavior
  • Room-scale and interaction preferences

Change one setting at a time. If a layout becomes unusable, restore the related VR option before changing render quality.

Image quality and performance

  • Begin with a moderate Minecraft render distance.
  • Disable shaders while testing a new setup.
  • Keep Intel Arc graphics drivers current.
  • Close unnecessary GPU-heavy overlays and recording applications.
  • Use a stable wired or low-latency network connection for Virtual Desktop.
  • Increase quality gradually after confirming stable head tracking.

Sodium is optional. When adding Sodium or visual mods, test them one at a time so the source of rendering problems remains clear.

Mod compatibility

Client-side content and performance mods are more likely to work than mods that replace the camera, framebuffer, shaders, menus or player rendering. Weather, shader and volumetric-effect mods may require specific compatibility work because VR renders two eyes.

When testing a mod, first confirm DigammaXR works alone. Add Fabric API and then add other mods individually. A successful launch does not guarantee correct stereo rendering.

Multiplayer

DigammaXR is client-side and can connect to many vanilla-compatible servers. Server anti-cheat may treat teleporting, crawling, unusual reach or room-scale movement as invalid. Follow server rules and turn off movement features that a server does not allow.

Troubleshooting

The headset is completely dark

  1. Confirm Virtual Desktop is connected and VDXR is selected.
  2. Close SteamVR and any second OpenXR application.
  3. Close Minecraft completely, reconnect the headset and relaunch.
  4. Test DigammaXR without shaders or extra rendering mods.
  5. Attach latest.log if the problem continues.

No active OpenXR headset or runtime

The game cannot see an active VDXR session. Reconnect Virtual Desktop, confirm the runtime selection and start Minecraft only after the headset connection is active.

A controller is missing

  1. Check the controller battery.
  2. Wake both controllers before starting Minecraft.
  3. Verify both appear inside the Quest and Virtual Desktop interfaces.
  4. Reconnect Virtual Desktop and restart the game.

The left stick does not move the player

Confirm the left controller is tracked, movement is set to controller free-move and no Minecraft key-binding screen is capturing input.

The cursor does not work

Open a standard Minecraft menu, point with the controller and press the selection trigger. Temporarily remove menu-overhaul mods if the pointer remains unavailable.

Double cursor, misplaced HUD or menus

Reset the HUD distance and scale, recenter the seated or standing origin, and disable GUI-changing mods while testing.

Low FPS or freezing

Reduce render distance, disable shaders, close overlays, verify the graphics driver and test with only DigammaXR and its required loader components.

Minecraft crashes

Do not repeatedly relaunch without reading the crash report. Remove duplicate VR mods, verify Java 17 and compare the installed mod versions with Minecraft 1.20.4.

Logs and issue reports

A useful report should include:

  • Minecraft latest.log or the complete crash report
  • Intel Arc GPU model and driver version
  • Headset and controller model
  • Virtual Desktop version
  • Confirmation that VDXR was selected
  • Full installed-mod list
  • Exact steps that reproduce the problem

In Prism Launcher, open the instance log after the game closes and use its export or copy function. Do not submit only a screenshot of the last line; earlier messages usually contain the real cause.

Updating or removing DigammaXR

Update

  1. Close Minecraft.
  2. Remove the previous DigammaXR JAR from the instance.
  3. Add the new JAR and confirm only one DigammaXR version is present.
  4. Start once without adding other new mods.

Remove

Delete the DigammaXR JAR from the client's mods folder. Worlds are not stored inside the mod, but back up important worlds before changing any large mod configuration.

Building from source

Use a 64-bit JDK 17. Clone the repository, open a terminal in the source directory and run the included Gradle Wrapper:

.\gradlew.bat :fabric:build --no-daemon

The distributable remapped JAR is produced in fabric/build/libs. Development and shadow JARs are not intended for a normal launcher's mods folder.
