DigammaXR is a virtual reality modification for Minecraft Java Edition. It is a fork of Vivecraft designed to make Minecraft VR playable on Intel Arc graphics through Virtual Desktop and its VDXR OpenXR runtime.

Features

  • Tracked hands and motion controller interaction
  • Joystick movement and snap turning
  • Room-scale gameplay and VR menus
  • Inventory controls, teleporting and comfort settings
  • Optional Sodium support

Requirements

The tested configuration uses Windows, Minecraft 1.20.4, Fabric, Java 17, Virtual Desktop with VDXR selected, a Meta Quest 3S and Touch Plus controllers.

Installation

  1. Install Fabric Loader for Minecraft 1.20.4.
  2. Place the DigammaXR JAR in the instance's mods folder.
  3. Select VDXR in Virtual Desktop Streamer.
  4. Connect the headset and start Minecraft.
